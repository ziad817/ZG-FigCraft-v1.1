تفاصيل ومميزات البرنامج

التخطيط التلقائي (Auto Layout)

تحكم كامل بالاتجاهات، الهوامش والمسافات، دعم كامل لخاصية Hug و Fill و Fixed لتصميم متجاوب مع جميع الشاشات.

نظام المكونات والمتغيرات

إنشاء مكونات رئيسية وحزم متغيرة (Variants) مع إدارة متغيرات الألوان، الخطوط، والأنماط للأوضاع الفاتحة والداكنة.

شبكات متجهات حقيقية

أدوات رسم متجهات فائقة الدقة (Pen & Pencil)، عمليات منطقية (Boolean) قابلة للتعديل المستمر، وسماكات خطوط متغيرة.

وضع المطورين (Dev Mode)

قياسات دقيقة للمسافات مع إمكانية تصدير الأكواد الجاهزة مباشرة بصيغ CSS و HTML و React و SwiftUI و Compose.

تجربة تصميم حديثة وخفيفة الوزن

برنامج ZG Fig craft هو الحل الاحترافي المتكامل للمصممين والمطورين لإنشاء واجهات المستخدم والنماذج المبدئية التفاعلية بسرعة وسلاسة استثنائية. تم بناء البرنامج بمحرك فائق الدقة يوفر استجابة فورية وسرعة فائقة في معالجة الملفات الضخمة دون أي بطء أو استهلاك غير مبرر لموارد جهازك.

أبرز إمكانيات النظام:

  • العمل بدون إنترنت وخصوصية تامة: تحفظ ملفاتك محلياً بصيغة .figcraft على قرصك الصلب دون الحاجة لتسجيل حساب أو تتبع لبياناتك.
  • دعم استيراد وتصدير واسع: دعم كامل لفتح وتصدير صيغ SVG و PNG و JPG و WebP و PDF بالإضافة إلى فتح ملفات .fig.
  • أدوات النماذج التفاعلية: ربط الشاشات، إنشاء تفاعلات ذكية مع انتقالات متحركة سلسة لمحاكاة التطبيقات الحقيقية.
  • محرك أوامر وذكاء اصطناعي مدمج: يتيح التحكم بأكثر من 400 أمر عبر واجهة سطر الأوامر (CLI) وقنوات التحكم البرمجية لتسريع عمليات التصميم الآلي.
